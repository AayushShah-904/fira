# Sprint 001 — Implementation

This folder accumulates notes on what was actually built during the sprint, including any deviations from `design/`. Expected contents (added as work progresses):

- `change-log.md` — chronological log of significant commits and their motivation
- `deviations.md` — anywhere the implementation differs from the design, with the reason
- `gotchas.md` — surprises encountered (Bicep quirks, Container Apps oddities, Azure SDK behaviors) and how they were resolved
- One file per major workstream as needed, e.g., `storage-adapter-refactor.md`, `bicep-apply-notes.md`

The goal is that someone reading this folder after the sprint can understand not just what was built but **why specific implementation decisions were made**, especially where reality diverged from the plan.
